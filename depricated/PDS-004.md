# 1 Purpose

This document defines the formal grammar of PuzzleDSL.

It specifies

• Legal document structure

• Legal object hierarchy

• Object placement rules

• Scope

• Lifetime

• Visibility

• Ordering

No implementation may interpret PuzzleDSL differently.

---

# 2 Philosophy

PuzzleDSL follows one rule.

Everything has exactly one legal location.

If an object appears somewhere else,

The document is invalid.

Example

VALID

Question

└── Entities

INVALID

Answer

└── Entity

Entities never belong inside Answer.

---

# 3 Top Level Grammar

Every PuzzleDSL document SHALL follow exactly this order.

Document

├── Metadata

├── Imports

├── Definitions

├── Entities

├── Rules

├── Timeline

├── Interaction

├── Solution

├── Explanation

└── Validation

Missing sections invalidate the document.

# 6 Definitions

Purpose

Prevent duplication.

Example

Grid Size

Shape Library

Colour Palette

Direction Set

Definitions contain immutable values.

Rules cannot modify Definitions.

---

# 7 Entity Grammar

Entity

├── id

├── type

├── properties

├── state

└── constraints

Every entity SHALL contain exactly one ID.

Entity IDs are globally unique.

---

# 8 Property Grammar

Property

├── name

├── value

└── inherited

Properties never exist independently.

Every property belongs to one entity.

---

Rule

├── id

├── trigger

├── target

├── action

├── priority

├── condition

└── constraints

Rules modify states.

# 10 Timeline Grammar

Timeline

├── Initial State

├── Frame 1

├── Frame 2

├── Frame n

└── Final State

Timeline defines progression.

Rules execute between frames.

# 21 Grammar Constraints

Every Entity must appear before first Rule.

Every Rule must appear before Timeline.

Every Timeline must exist before Solution.

Every Solution must exist before Explanation.

---

# 22 Compiler Behaviour

Compiler SHALL

Resolve IDs

Expand Definitions

Check References

Validate Constraints

Generate Render Model

Compiler SHALL NOT

Guess values

Repair invalid questions

Generate answers

Modify logic
